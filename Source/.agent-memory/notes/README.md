# Notes

Temporary, uncurated project notes belong here.

Do not use this folder as the default destination for durable context. If a user-provided or agent-captured note is clear and durable, curate it immediately into a rule, memory, or uncertainty.

Use `notes/pending.md` only when immediate curation is unsafe, unclear, or disruptive.

Use `.agent-memory/templates/pending-note.md` for structured pending notes.

Review pending notes during `/memory-refresh` and either promote them to rules or memories, convert them to uncertainties, archive them, or remove them from active memory.
