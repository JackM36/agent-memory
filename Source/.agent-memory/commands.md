# Memory Commands

Source-of-truth workflows live in `.agent-memory/commands/`. Native wrappers should stay thin and point to these files.

- `/memory-add <context>` -> `.agent-memory/commands/memory-add.md`
- `/memory-query <topic>` -> `.agent-memory/commands/memory-query.md`
- `/memory-file-history <path>` -> `.agent-memory/commands/memory-file-history.md`
- `/memory-init` -> `.agent-memory/commands/memory-init.md`
- `/memory-refresh` -> `.agent-memory/commands/memory-refresh.md`
- `/memory-maintain <handoff>` -> `.agent-memory/commands/memory-maintain.md`
- `/memory-prune` -> `.agent-memory/commands/memory-prune.md`
- `/memory-resolve <uncertainty>` -> `.agent-memory/commands/memory-resolve.md`
- `/memory-scout <task>` -> `.agent-memory/commands/memory-scout.md`
