# Templates

Canonical templates for creating memory-system files.

Use these files as the source of truth when creating new entries. Folder README files explain purpose only and should point here instead of duplicating full templates.

## Files

- `memory.md` creates entries in `.agent-memory/memories/`.
- `rule.md` creates entries in `.agent-memory/rules/`.
- `uncertainty.md` creates entries in `.agent-memory/uncertainties/`.
- `report.md` creates entries in `.agent-memory/reports/`.
- `pending-note.md` creates pending notes.
- `memory-scout-result.md` defines memory scout output.
- `memory-maintenance-handoff.md` defines the main-agent handoff for post-work maintenance.
- `memory-maintenance-result.md` defines memory maintainer output.
- `agents-section.md` contains the section to add to a project's `AGENTS.md`.
- `manifest-rule-entry.md` creates manual rule index entries.
- `manifest-memory-entry.md` creates manual memory index entries.
- `manifest-uncertainty-entry.md` creates manual uncertainty index entries.
- `manifest-report-entry.md` creates manual report index entries.
